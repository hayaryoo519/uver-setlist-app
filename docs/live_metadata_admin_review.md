## 操作の入口

管理画面のLive Events一覧で、対象公演の「属性」ボタンを選択する。
既存のEdit Live / Edit Setlistとは別のモーダルを開く。
この画面から公演名・日付・特記事項・セトリを変更しない。

## 表示する情報

- 保存済みの有効タグ、開催国、対象メンバーと確認状態。
- 未確認の自動タグ・国・対象メンバー候補。
- 取得元間の国候補の不一致。
- 取得元IDごとの属性・国候補、出典リンク、抽出済み原文（折りたたみ表示）。

対象メンバーについて、「未確認」と「対象なし・確認済み」を区別する。
国候補は表示しても、勝手に確認済みにしない。
リンクはhttp/httpsに限定し、別タブで開く。
原文はテキスト表示し、取得HTMLや説明をHTMLとして実行しない。

## 保存する手動設定

### タグ

各固定タグについて、以下を選択できる。

- 自動候補に従う：手動追加/除外しない。
- 付ける：再取得で候補から消えても手動追加を維持する。
- 除外する：再取得で候補に含まれても除外を維持する。

一部のタグを変更しても、他の既存手動追加/除外を保持する。
「タグをすべて自動候補へ戻す」はtagOverridesをnullで送信する。
海外公演はタグ欄に設けず、確認済みの開催国から導出する。
フェスは既存のライブ種別で扱う。

### 開催国

「開催国を確認済みにする」を選び、ISO国コードを入力する。
自動候補があれば初期入力として表示するが、保存するまで確定しない。
コードは大文字で送信し、ISOコードの有効性はAPIで検証する。
「未確認／自動候補へ戻す」はcountryをnullで送信する。

### 対象メンバー

確認済みモードでは複数選択できる。
未選択で保存すると「対象なしと確認済み」。未確認モードへ戻すとmembersをnullで送信する。
対象メンバーの確定は生誕祭の根拠になる。
生誕祭を除外したままメンバーを確定する矛盾はAPIで拒否し、入力を保持する。

### 共演者

確認済みモードで正式名/別名を検索し、登録済みIDと役割を選び追加する。役割変更・関連削除も可能。
未選択で保存すると「共演者なしと確認済み」。未確認へ戻すとparticipants=nullで関連を解除する。
対バン相手の確定はvsタグの根拠とし、vs除外との矛盾は拒否する。フェスの全出演者を対バン相手にしない。
新規アーティスト登録や辞書の名前/別名修正も可能。ただし辞書は即時保存、公演関連は「追加情報を保存」で別途保存する。
辞書変更時は他公演でも参照されるため一覧と全詳細キャッシュを無効化する。

### 分類検討

「既存分類に収まらない・分類検討が必要」と管理メモを保存できる。
自由な公開タグを生成する機能ではない。
手動設定の解除はclassificationをnullで送信する。

## 更新・失敗時の扱い

- 変更した項目だけPATCHする。未編集項目を送信しない。
- GETで取得したrevisionを送信し、成功時は返された保存済み情報とrevisionに置き換える。
- 成功後に公演一覧と対象の詳細キャッシュを無効化する。合成APIのPC/モバイル実ブラウザで反映も確認済み。実環境の結合確認は未実施。
- 保存中は再保存/閉じる/再読み込みを禁止する。
- 409は入力を保持し、再読み込みするまで保存を禁止する。自動再送しない。
- 最新情報の読込失敗後は、前回情報があっても保存を禁止する。
- 400等の保存エラーでは入力を保持し、修正して再保存できる。
- 未保存入力がある場合、閉じる/再読み込みで破棄確認を行う。
- 読込要求は閉じる/切替時にAbortControllerで取り消す。
- ダイアログの名前、ラベル、エラー/保存通知を設定。Escape、Tab循環、閉じた後のフォーカス復帰を備える。
