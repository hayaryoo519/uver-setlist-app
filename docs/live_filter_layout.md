# ライブ一覧：詳細フィルターの表示整理

## 表示は3グループ

| グループ | 項目 |
|---|---|
| 公演の特徴 | 男祭り・女祭り・生誕祭・クリスマス・周年記念。必要時に生誕祭の対象メンバー |
| 共演 | 対バン公演・共演アーティスト・相手の出演形態 |
| 開催地 | 国内（日本）・海外全体・個別の国・開催国未確認を一つの選択欄に集約 |

基本のキーワード・年度・ワンマン/FES/EVENT・楽曲は詳細フィルターに移さない。
詳細は初期状態で閉じ、適用件数・解除可能なチップを表示する。

## 検索の意味を変えないための扱い

- 表示グループは `LIVE_TAG_GROUPS` の検索分類と独立させる。見出しをまとめても `matchesLiveTags` の判定は変更しない。
- 海外全体は既存の `overseas` 条件、国内は確認済み国 `JP`、個別の国は既存の国条件へ対応させる。国不明を国内扱いしない。
- 開催地を選び直したときにだけ海外タグ/国条件を一本化する。過去に保存された複数条件は復元時に勝手に解除しない。
- 国名は表示のみ日本語化し、コードの保存値・APIは変えない。現在の取得結果にない復元済み国も選択欄とチップに残す。
- 生誕メンバー欄は生誕祭タグの選択時、またはメンバー条件が有効なときに表示する。タグ解除やパネルを閉じるだけでメンバー条件を解除しない。
- メンバー選択時に生誕祭タグを暗黙に追加しない。記念日タグの組み合わせによって検索結果を広げてしまうため。
- 対バン公演は相手未確認も含む。出演形態は確認済みの共演関係を指定する。両者を同一条件として置き換えない。
- アーティストと出演形態を併用するときは、同じ出演関係に一致する必要がある。別アーティストのゲスト出演等で一致させない。
- 生誕祭の対象が不明でも生誕祭タグで探せる。候補メンバーを確定済みとして検索しない。
- 開催国未確認の公開検索は今回維持する。管理向けだけに移すかは別途判断する。

## 将来の追加方針（未実装）

- 都道府県・都市・会場は開催地の詳細。複合タグを増やさない。
- FC限定や年齢制限は参加条件。男祭り・女祭りという企画名と混同しない。
- 演奏形式・昼夜・中止/延期は、それぞれ独立した軸として実例・検索需要・登録根拠を確認してから検討する。
- 生誕メンバー名・共演者名・ツアー名を新しいタグにしない。構造化した対象や既存の名前検索で扱う。
- 公演種別と会場種別（HALL/ARENA/LIVEHOUSE）の分離は別途データ設計・互換性検討が必要。この表示整理では変更しない。

保存・確認状態の契約は [ライブ属性設計](./live_metadata_design.md)、公開検索は [公開表示・検索](./live_metadata_public.md) を参照。
