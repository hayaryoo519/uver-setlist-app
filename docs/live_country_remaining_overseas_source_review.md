## ハワイ以前をまとめて扱う案の予備調査（未適用）

2024-04-11より前のProduction公開公演は924件、うち国未確認は**898件**。会場空欄は0件だが、2020-06-06 / 2020-07-06の2件は `PIA LIVE STREAM` と記録されており、物理的な日本開催を自動確定しない。他にも配信・誤同定・海外フェスなどの例外がないか調べる必要がある。

[BARKSの2024年3月の記事](https://barks.jp/news/527459)は4月11日のハワイ公演を「UVERworld初の海外公演」と記述。[音楽ナタリーの同年12月のアーティスト特集](https://natalie.mu/music/pp/uverworld05)も2024年のハワイ/韓国を「初の海外公演」と記述。同記事ではTAKUYA∞本人が韓国・ハワイへライブで行ったと話す。[UVERworld公式のハワイ公演告知](https://www.uverworld.jp/news/detail/2685)、[公演詳細](https://www.uverworld.jp/schedule/detail/2678)、[公式ツアー特設](https://www.uverworld.jp/feature/2024_live)は日付と `Honolulu,USA` を確認できるが、確認した本文中には**「初の海外公演」の明示はない**。Wikipedia/報道記事を一次資料の代用として898件すべてをJP確定しない。

効率化するなら、まず公式/主催者による「初」の対象範囲を確認し、実公演と配信を仕分けた**期間ルールの候補集合**を作る。暫定的には898件から配信の2件を除いた**最大896件**が次の同定・対象範囲レビュー対象であり、保存可能件数ではない。会場/公演名の海外キーワード検査では9件がヒットしたが、`HAWAIIAN6`（日本の対バン相手）や `Kokusai`（国内の会館名）などの偽陽性を含み、語句だけで国を確定/除外しない。公演ごとの既存管理値・revisionを本番で新たに検査し、利用者への一括方針・例外提示と承認後に国だけ個別保存する。ここでは候補の確定・PATCH・DB操作は一切行っていない。
