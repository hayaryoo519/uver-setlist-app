## 公開API

`GET /api/lives` / `GET /api/lives/:id` に以下を追加する。

```json
{
  "tags": ["birthday", "overseas"],
  "metadata": {
    "country": { "code": "KR", "status": "confirmed" },
    "members": { "ids": ["takuya"], "status": "confirmed" },
    "participants": { "items": [{ "artistId": 10, "name": "Fixture Artist", "aliases": ["FA"], "role": "guest" }], "status": "confirmed" }
  }
}
```

- タグは取得元別の候補集約に手動追加/除外を適用した有効タグ。
- 海外属性は確認済み開催国がJP以外の場合のみ導出する。
- 国・対象メンバーは手動確認済みの値のみ返す。未確認はcode=null/ids=[]とstatus=unreviewedを返す。
- 確認済みでメンバーids=[]は、未確認の空配列と区別できる。
- candidates/overrides/原文スナップショット/取得元/不一致/分類検討メモ/履歴は公開しない。
- 正式名称や公開特記事項は、既存の公演情報として従来どおり返す。原文と同じ文字列を含み得るが、管理用スナップショットそのものは返さない。

`server/services/publicLiveMetadata.js` で公開用投影を共通化する。
一覧は公演ごとの追加クエリではなく、取得した全公演の属性を1回のANYクエリで取得する。
一覧と詳細で同じ有効情報計算を使う。旧公演の判定は管理レビューと共通化したが、レビュー理由/件数等は公開しない（[管理レビュー導線](./live_metadata_review_queue.md)）。
共演者の辞書も必要なIDをまとめて1回取得する。確認済み関連だけに正式名/別名/役割を返し、辞書revisionや履歴は公開しない。

### 旧公演の扱い

候補タグがまだ保存されていない手動登録/旧公演は、サーバー側で正式名称・タイトル・特記事項から固定タグを判定する。
日付から生誕祭や会場/タイムゾーンから海外を推測しない。
手動追加/除外があればフォールバック結果にも適用する。
保存済みの候補tags=[]は明示的な空として扱い、名称から再生成しない。
過去に推測で記入された特記事項自体を一律削除する移行処理は行わない。必要な公演から管理者レビューで訂正する。

## フロントエンドの扱い

取得フック/正規化の `withLiveTags` は、APIにtags配列があれば空配列も含めて優先する。
APIのタグをタイトルから再判定して上書きしない。
古いAPIや他の集計データでtagsがない場合だけ、フロントの固定辞書へフォールバックする。
正規化では公開metadataも保持する。

管理画面保存後には一覧と対象公演の詳細キャッシュを無効化する。
詳細キーは数値ID/文字列IDの両方を考慮する。

## 一覧・詳細の表示

`src/components/LiveMetadataBadges.tsx` を一覧（PC/モバイル）と詳細で共用する。
有効タグと、確認済みの開催国コード・生誕祭メンバー・共演者の役割と正式名を表示する。
未確認の構造化情報、確認済みの対象なしはバッジにしない。
正式名称に男祭り等が残っていても、タグ除外は正式名称を消す操作ではない。

## 一覧の検索

- 固定タグ：男祭り、女祭り、対バン、生誕祭、クリスマス、周年記念、海外公演。
- フェス：既存のFES種別フィルターを使用し、重複するフェスタグフィルターを廃止する。
- 開催国：確認済み国コードで検索できる。「開催国未確認」は国内/海外と区別して検索する。
- 生誕祭の対象メンバー：確認済み対象IDだけで検索する。
- 共演者：確認済みアーティストIDと役割で検索。両方指定した場合は同じ関連項目に一致させる。文字検索では正式名/別名も対象にし、NFKC・小文字化で表記ゆれを扱う。
- 同一タグ分類内はOR、分類間はAND。国・メンバー・年度・文字・種別・楽曲の条件ともAND。
- PC/モバイルで選択状態を共有し、件数バッジ・解除チップ・全解除に反映する。
- 既存と同様、属性・国・メンバーは取得済み一覧に対するクライアントフィルター。APIの検索クエリにはまだ追加しない。
- ルーターstateを使い、URL共有には条件を含めない。
- 試作のフェスタグがルーターstateに残っていた場合は、FESTIVAL種別へ移す。
