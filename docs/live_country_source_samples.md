# 開催国補完：公開出典の少数照合（未承認・未適用）

2026-10-17、Stagingの匿名公開GETと公開公式サイトのHTTP GETのみで4公演を調査した。
DB/候補/確定値の更新、再取り込みジョブ、外部APIキーの使用、本番接続は行っていない。
公開出典の特定と国の根拠確認を分け、元のタイトル・ツアー・会場・属性を変更していない。

公開リストでは対象の4日それぞれに1公演があった。ただし、それだけで実際の昼夜公演の有無や、他環境の公演との一意対応を保証しない。
少数の選択例であり、全626公演の整備率を推定するサンプルではない。
Stagingの読み取り専用集計で `lives.prefecture` は全642件NULLと確認。この列からの国内一括判定もできない。
2019年末の根拠は公式特設ページの**その公演の日付に対応する所在地**であり、会場名や他年の情報から国を推測したものではない。

1CHANCEは当初「国名の直接表記未確認」として保留したが、ユーザーの国内フェス/熊本という指摘を受け、主催者の当該公演の会場/住所欄を再確認した。
公式住所は `熊本県合志市栄3802－4（〒861-1113）`。この明示住所に基づいてJP候補に訂正した。
日本の公演の根拠に必ず国名文字列「日本」が必要とした初回判断は厳しすぎた。
ただし、会場名だけで国を当てたり、住所未確認の他公演を一律JPにしたりするルールは導入していない。
匿名公開APIで種別は既にFESTIVAL、国だけがunreviewedと確認。種別の変更は不要で、補正対象は国だけ。
出典の確認と、実データへの確定操作の承認/管理者認証は別であり、まだ保存はしていない。

## 候補データとテスト

`docs/fixtures/live_country_source_samples.json` に公開情報だけを記録した。
**インポート用ファイルではない。** Staging/本番の公演ID・revision・操作者・承認日時・overridesは含めない。
全件 `reviewStatus=unapproved`、コレクションは `applied=false`。国の提案はKRが1件・JPが2件、残り1件はnull。
「国名未確認」は日本ではないという判断ではなく、この調査で採用する国根拠の検証が未完了という意味。

`server/tests/utils/countrySourceSamples.test.js` で、ISO国コード検証と次を確認する。

- 根拠未確認/会場別名未確認の例にJPを補わない。
- 国候補がKR/JPでも、有効値は未確認のままで、海外タグや国内検索対象に自動昇格させない。
- 1CHANCEの根拠は公演に対応する公式住所とし、既存のFESTIVALを変更対象にしない。
- 出典と提案の対応を持たせ、未承認データに保存先IDや手動確定値を混ぜない。

このテストは候補/公開の分離を確認するもので、出典の恒久的な正しさや人間による承認を証明するものではない。

## 次の判断

- KR 1例・JP 2例は、操作承認と正規の管理者認証が揃えば候補登録/確定の検証に使える。現時点では未適用。
- 残る国内例は、**当該公演の公式住所等に対応する根拠**を確認する。既存の会場名だけから国を当てない。
- 一般的な「日本」の文字列検索は使わない。「日本武道館」・日本語窓口・スポンサー名・国内外チケット受付などは開催国の根拠ではない。
- 本番/他環境への適用には公演IDとrevisionの再照合が必要。会場名の省略や同日複数公演を自動で丸めない。
- 国だけの補完で公演名・曲・他の属性・共演者を変更しない。実環境への候補保存/確定は別途承認が必要。
