# 開催国：公式ツアー日程による一括候補プレビュー（未保存）

2026-10-18、Stagingの匿名公開APIとUVERworld公式の[2024年特設日程](https://www.uverworld.jp/feature/2024_live)・[2025年特設日程](https://www.uverworld.jp/feature/2025_live)を読み取り専用で照合した。公演IDはその時点のStaging公開IDで、別環境のIDや保存時revisionではない。**管理候補・手動値の保存、再取り込み、DB更新、Production接続は行っていない。**

## 一括照合の条件

公式HTMLの各日程行に独立して表示される**公演日・地域欄・会場欄**だけを使う。Stagingの国未確認レコードと同日・同会場（Unicode幅と空白の差だけ正規化）で、**その日のStaging記録と公式日程がそれぞれ1件**のときだけ候補にする。2024年は地域欄が `JAPAN` / `KOREA` または都道府県名（北海道、大阪府など）、2025年は都道府県名である場合に限定する。地域欄の「東京」「福岡」など県名を省いた値はこの機械的プレビューでは除外する。公演名や会場名に含まれる都道府県文字列、タイムゾーン、URLの国別ドメインは国の根拠にしない。

公式特設日程に該当するHTML行は2024年45行、2025年14行。そのうち**厳密な日付・会場・明示地域の一致は15件（JP 14 / KR 1）**。これは自動承認件数ではなく、保存前のレビュー対象を絞った件数。タイトルやツアー、会場の細部、出典ページが変わっていないかは保存直前に再照合する。

## 除外例と後続の境界

- 2025-12-25はStagingも公式日程も昼夜2件。会場が同じでも公演単位の対応はこのプレビューから除外。
- 2025-12-30のStaging「マリンメッセ福岡」と公式「マリンメッセ福岡A館」、2025-11-29/30の「朱鷺メッセ」と公式「朱鷺メッセ 新潟コンベンションセンター」は、表記差があるため機械的照合から除外。既存の2025-12-31の個別レビューを他日程へ汎用適用しない。
- 2025-12-26は公式地域欄が「東京」。公演名や会場名「日本武道館」に頼ってJPにせず、別の当該公演の所在地を確認する。
- 2024年の地域欄には「滋賀」「福岡」「香川」等の県名省略値も多数ある。都道府県名への地名辞書変換は今回行わない。
- 2024・2025年に先に個別調査した[6件](live_country_2024_2025_source_review.md)とは重複しない。2026年の[3件](live_country_next_source_review.md)も別。**追加の未保存レビュー候補は累計24件（JP 23 / KR 1）**で、Stagingの確定済み件数を増やしたものではない。

この方式なら全公演を手作業で最初から読む必要はない。ただし保存は別途対象を明示した承認後、各レコードで最新の公演・候補・手動国・revisionを再取得し、国だけを1件ずつPATCHする。競合や不一致があれば停止する。未照合・不確かな公演は未確認のまま残す。
