# Decision Log

このファイルは、仕様や実装の「決定理由」を引き継ぐための記録です。
単なる最新仕様は `SPECIFICATIONS.md` に書き、なぜ採用したか・なぜ取りやめたか・いつ再検討するかはここに残します。

## 記録するもの

- 機能を追加・延期・取りやめた理由
- UI/UX やデータ設計で迷った末の判断
- 後から見たときに「なぜこうなっているのか」が分かりにくい制約
- 再検討条件がある判断

## テンプレート

```md
## YYYY-MM-DD: 決定タイトル

### 背景

### 決定

### 理由

### 代替案

### 再検討条件
```

## 2026-05-26: 参戦年表を取りやめる

### 背景

My Page または公開プロフィールで、ユーザーの参戦履歴を年表形式で振り返れるようにする案があった。

### 決定

参戦年表は現時点では実装しない。

### 理由

- 参戦記録一覧と公開プロフィールで、現在の主要な閲覧用途は満たせる。
- 初期実装コストに対して、年表形式の利用頻度がまだ不明。
- モバイル表示では情報量が増えやすく、既存の My Page 導線を複雑にする可能性がある。

### 代替案

- 参戦ライブ一覧の年別フィルタ
- 参戦ライブ数の年別集計
- プロフィール上のシンプルな参戦サマリー

### 再検討条件

- ユーザーから参戦履歴の振り返り要望が増えたとき。
- My Page または公開プロフィールの分析機能を拡張するとき。
- 参戦記録データを使った共有・投稿機能を追加するとき。
